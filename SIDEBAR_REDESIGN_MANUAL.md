# Avenera sidebar redesign — manual checklist

Use a local static server or the existing app shell to review the redesign at desktop and mobile widths.

- [ ] Desktop sidebar is a neutral surface approximately 248px wide with a restrained border and no purple full-height panel.
- [ ] Section labels, icons, item spacing, hover states, and keyboard focus rings are visually consistent.
- [ ] The current page keeps a subtle purple active treatment after navigation; only one item is active.
- [ ] Dashboard, Transações, Planejamento, Relatórios, Contas, and the profile/settings navigation still route to their existing pages.
- [ ] Export/import controls remain available and the profile/footer treatment still updates from the user record.
- [ ] Theme toggle changes the sidebar to the charcoal dark surface and keeps text/icons legible.
- [ ] At a mobile viewport, the hamburger opens the sidebar, the overlay appears, and clicking the overlay closes it.
- [ ] At a mobile viewport, main content is not permanently shifted to the right by the closed sidebar.
- [ ] Notification drawer, Anora menu, floating action menu, modals, and page renderer output remain unaffected.
- [ ] Check at least one narrow phone width and one wide desktop width for clipping or horizontal overflow.

Build note: this workspace did not have the npm executable available, so `styles.css` was updated with the same scoped block as `input.css` rather than regenerated by Tailwind.
